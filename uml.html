1. Data Model & Component Class Diagram

classDiagram class Users { +int id +string username +string password_hash +string role +datetime created_at } class Tenants { +int id +string name +string hostname +string environment +int is_blocked +datetime created_at } class TenantEnv { +int tenant_id +string key +string value } class AdminLogs { +int id +string tenant_name +string action +string details +datetime created_at } class AdminDashboard { +login(username, password) +getMetrics() +createTenant(name, password, env) +toggleBlock(id) +resetPassword(id, password) +deleteTenant(id) +getLogs(source, tenant) } class TerminalServer { +loadTenants() +initTenantContext(req) +isAuthorized(req) +spawnPTY(cwd, tenantEnv) +getMetrics() } Tenants "1" --> "*" TenantEnv : has AdminDashboard --> Users : authenticates AdminDashboard --> Tenants : manages AdminDashboard --> AdminLogs : records TerminalServer --> Tenants : reads .conf

2. Tenant Provisioning & Login Sequence

sequenceDiagram actor Admin actor Tenant participant AdminPHP as Admin Dashboard (:8082) participant DB as SQLite & /etc/webvm/tenants participant Apache as Apache (:8081) participant Term as Terminal Server (:7681) Admin->>AdminPHP: Login (adminman) Admin->>AdminPHP: Create Tenant (name, password, env) AdminPHP->>DB: Insert tenants + tenant_env, write {name}.conf & {name}.log AdminPHP->>Apache: Write /etc/apache2/conf.d/tenants/{name}.conf & /var/www/tenants/{name} Tenant->>Term: GET http://localhost:7681/ Term-->>Tenant: 401 ZunoX Tenant Login HTML Tenant->>Term: POST /api/tenant-login (username, password) Term-->>Tenant: 200 Set-Cookie: zunox_tenant_session Tenant->>Term: WS Upgrade (?tenant={name}) Term-->>Tenant: PTY Shell in /var/www/tenants/{name} (root@{name}/webvm)
